# SEO operations workbench definition

The `/icerik/seo` workbench should answer, at a glance:

- What is blocking indexability now?
- Which published TR pages are missing title, description or canonical?
- Which pages are intentionally noindex?
- Are sitemap and robots contracts safe?
- Is social preview fallback available?
- Are homepage role-card/on-page signals healthy?
- Are footer/internal links safe and non-broken?
- What is the next canonical editor/action for each issue?

The workbench diagnoses and routes; it must not become a second SEO write source.
